# CODING_STANDARDS.md

# Mandatory Rules

- Strong typing
- No magic strings
- No duplicated logic
- Reusable components
- Small focused classes
- Small focused functions
- Clear naming
- Interface-driven architecture
- Feature modularity

---

# Formatting

- ESLint
- Prettier
- Strict TypeScript
- Conventional commits

---

# Breaking Changes

- No breaking changes without documentation
- Migration path required
- Deprecation strategy required

---

# Code Quality

- Prefer composition over inheritance
- Extract shared logic
- Keep platform code minimal
- Shared business logic first
